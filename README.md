Awebstore Electronics

Template katalog elektronik responsif untuk laptop, smartphone, dan aksesori.

Tentang Proyek

Awebstore Electronics adalah proyek katalog produk berbasis HTML, CSS, dan JavaScript. Template ini dirancang sebagai dasar untuk membangun halaman katalog sederhana yang bisa dikembangkan sesuai kebutuhan toko.

Fitur yang Direncanakan

- Tampilan responsif untuk HP dan komputer.
- Pencarian produk berdasarkan nama.
- Filter kategori produk.
- Kartu produk dengan gambar, spesifikasi, dan harga.
- Struktur kode yang mudah diedit.

Kategori Produk

- Laptop
- Smartphone
- Aksesori elektronik

Teknologi

- HTML
- CSS
- JavaScript

Cara Menjalankan

1. Buka "index.html" melalui browser atau hosting statis yang sesuai.
2. Edit kode untuk mengganti data produk, gambar, harga, dan identitas toko.
3. Uji semua fitur sebelum digunakan.

Status Proyek

Proyek ini masih dalam tahap pengembangan. Data produk dan harga contoh digunakan untuk demonstrasi, bukan penawaran barang nyata.

Hak Penggunaan

Sebelum template didistribusikan atau dijual, periksa lisensi seluruh kode, gambar, font, dan aset pihak ketiga. Ketentuan pengalihan hak atas proyek perlu ditentukan secara jelas.

Batasan

Template ini merupakan katalog demonstrasi, bukan sistem e-commerce lengkap. Pembayaran, inventaris, dan pengelolaan pesanan belum termasuk kecuali dikembangkan secara terpisah.
